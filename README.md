# SISTEM PERHITUNGAN BIAYA PARKIR

Penjelesan 

1. tarif_parkir
   Menyimpan tarif parkir berdasarkan jenis kendaraan, yaitu mobil Rp5.000/jam dan motor Rp3.000/jam.

2. hitung_biaya_parkir
   Menghitung total biaya parkir berdasarkan jenis kendaraan dan lama parkir. Jika parkir kurang dari 1 jam, waktu dibulatkan ke atas menjadi 1 jam.

3. hitung_durasi
   Menghitung lama parkir dari selisih antara jam masuk dan jam keluar.

4. data_kendaraan
   Berisi data kendaraan yang parkir, seperti jenis kendaraan, jam masuk, dan jam keluar.

5. Perulangan for
   Memproses setiap data kendaraan untuk menghitung durasi dan biaya parkir.

6. print
   Menampilkan hasil perhitungan dalam bentuk **struk biaya parkir**, yang berisi jenis kendaraan, jam masuk, jam keluar, lama parkir, dan total biaya.
